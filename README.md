# 🎁 Amigo Secreto

Sorteo de amigo secreto en un solo archivo HTML (sin servidor).

- Varios eventos/grupos, cada uno con su sorteo.
- Cada participante ve su resultado con un enlace o código personal.
- Los datos del organizador se guardan en su navegador; usa «Descargar respaldo» para no perderlos.

Publicado con GitHub Pages desde la rama `main`, carpeta raíz.
